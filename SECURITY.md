# Security

- **Problems in this kit** (compose files, scripts, docs): use GitHub's private vulnerability reporting (Security tab -> Report a vulnerability). Do not open a public issue for something exploitable.
- **Problems in the server itself** (OAuth, token store, tools): report them to [bakissation/mcp-google-multi](https://github.com/bakissation/mcp-google-multi) through its private reporting channel.
- Never paste tokens, client secrets or the contents of `.env` into an issue.

See "Safety notes" in the [README](README.md) for the known limitations of the pinned upstream version.
